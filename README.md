# UniTask

An offline-first Android app for managing university life: assignment deadlines, class timetable, and courses in one place. I built it for myself as a student, because I wanted one app that knew both my classes and my deadlines.

> **Built with AI assistance.** This app was vibecoded in [Google AI Studio](https://aistudio.google.com/). I direct the features and test the result, but most of the code was generated by AI. Treat it as a personal tool I use, not as a showcase of hand-written Android engineering.

## Features

- **Deadlines tab:** tasks with due date and time, priority (low, medium, high), status (pending or done), and a course tag.
- **Timetable tab:** weekly lecture slots per course, plus a card showing your current and next class.
- **Courses tab:** course code, name, instructor, location, and a color tag, with a count of tasks per course.
- **Reminders:** choose one or several notifications per task (at the deadline, 2 hours before, 1 day before).
- **Attachments:** attach files to a task, stored on the device.
- **Optional cloud backup:** sign in with Google to back up courses and tasks to Firestore. The app works fully offline without it.

## Tech stack

- Kotlin, Jetpack Compose (Material 3)
- Room for local storage
- WorkManager for background sync, AlarmManager for reminders
- Firebase Auth, Credential Manager, and Firestore for the optional backup
- Min SDK 24, target SDK 36

The app starts empty on first launch. Add your courses first, then tasks and lecture slots.

## Running it

You need Android Studio and a device or emulator.

1. Clone the repo and open it in Android Studio.
2. Create a debug keystore in the project root. It is gitignored, and the build expects it:
   ```
   keytool -genkey -v -keystore debug.keystore -storepass android -alias androiddebugkey -keypass android -keyalg RSA -keysize 2048 -validity 10000 -dname "CN=Android Debug,O=Android,C=US"
   ```
3. Run the `app` configuration.

The app runs offline with no further setup.

### Cloud backup (optional)

Cloud backup will not work from a fresh clone, because the Firebase config is not in the repo. To enable it you would need to:

1. Create your own Firebase project with Authentication (Google sign-in) and Firestore.
2. Add your own `google-services.json` to `app/` (it is gitignored).
3. Replace the Firestore database ID in `app/src/main/res/values/firebase_applet_config.xml`.
4. Deploy `firestore.rules`, which restrict every document to its owner's user ID.

I have not tested this setup on a clean project, so expect to debug it.
